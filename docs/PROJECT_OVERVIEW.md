# 프로젝트 개요

화투패로 덱을 구성하고, 손패 3장 중 2장을 내어 섯다 족보와 적의 공개 패를 활용해 싸우는 싱글 플레이 로그라이트 덱빌딩 게임 프로젝트다.

## 세계관

귀신과 귀물이 모여 거래하고 교류하는 도시 `귀시장`이 있다. 도시의 중심에는 모든 승부가 이루어지는 `투전장`이 있으며, 귀시장에서는 신분이나 권력보다 승부의 결과가 우선한다.

> 여기선 도박에서 승리하는 쪽이 형님이다.

원래 작았던 투전장은 비광이 다른 광들의 힘을 빼앗아 귀시장으로 도망친 뒤 시장 전체를 집어삼킨 거대한 도박장으로 변했다. 힘을 빼앗긴 광들은 비광에게 조종당하는 중간 보스가 되었고, 주인공 비형은 조정의 명을 받아 비광을 체포하기 위해 투전장으로 향한다.

장기적인 서사 진행은 `귀시장 입장 → 일반 전투 → 광 중간 보스 → 비광 최종 보스`를 뼈대로 삼는다. 실제 데모의 전투 및 보상 순서는 `GAMEPLAY.md`의 상태가 표시된 런 구성 규칙을 따른다.

## 현재 단계

현재는 Unity 프로토타입 구현 준비 단계다. 첫 목표는 일반 전투 3회와 12월 비광 보스로 구성된 짧은 플레이어블을 만드는 것이다.

확정된 개발 환경:

- Unity `6000.3.21f1`
- Unity 2D / Universal Render Pipeline
- WebGL

플레이어의 카드 교체 기회는 전투당 1회로 확정했다.

기본 피해 공식은 구현 전에 고정하지 않고 세 후보를 시뮬레이션해 비교한다.
