# 게임플레이 명세

## 문서 상태

- 이 문서는 구현이 따라야 하는 게임 규칙의 단일 기준이다.
- 각 항목은 `확정`, `실험`, `미정`, `보류` 중 하나의 상태를 가진다.
- 상태가 `실험` 또는 `미정`인 규칙은 비교 가능한 형태로 구현할 수 있지만 기본 규칙으로 확정하지 않는다.

## 게임 핵심

**확정**

플레이어는 화투패로 덱을 구성하고, 매 턴 손패 3장 중 2장을 내어 섯다 족보와 적의 공개 패를 활용해 싸우는 싱글 플레이 로그라이트 덱빌딩 게임이다.

핵심 선택은 다음 세 가지다.

1. 현재 손패에서 어떤 두 장을 낼 것인가.
2. 적의 공개 패와 족보를 이길 조합을 만들지, 상성으로 받아칠 것인가.
3. 전투 보상으로 덱을 두껍게 만들어 새 족보를 열지, 보상을 건너뛰어 덱의 일관성을 유지할 것인가.

## 첫 번째 플레이어블 범위

**확정**

- 플레이어 캐릭터 1종
- 1~10월 패가 한 장씩 들어간 10장 시작 덱
- 한 번에 3장 드로우
- 손패에서 2장 제출
- 적의 제출 패와 예상 행동 공개
- 양쪽 패를 비교한 뒤 승자가 패자에게 피해 적용
- 일반 적 3종과 12월 비광 보스 1종
- 전투 후 카드 3장 중 1장 선택 또는 보상 건너뛰기
- 같은 월 카드를 덱에 추가해 땡을 만들 수 있음
- 단순 수치 강화 1종
- `일반 전투 3회 → 휴식/강화 → 보스`의 짧은 런
- 승리, 패배, 재시작

## 카드와 덱

### 카드 정체성

**확정**

각 카드는 최소한 다음 정보를 가진다.

- 고유 ID
- 월 숫자
- 패 변형
- 광, 띠, 열끗 등 게임에서 사용하는 태그
- 강화 단계

### 시작 덱

**확정**

- 1월부터 10월까지 각 한 장, 총 10장이다.
- 시작 덱에는 같은 월이 없으므로 땡이 나오지 않는다.
- 같은 월 패를 보상으로 추가하는 순간부터 땡 계열 빌드가 열린다.

### 드로우와 순환

**확정**

- 턴 시작 시 손패가 3장이 되도록 뽑는다.
- 플레이어는 2장을 제출한다.
- 제출하고 남은 패는 버린 카드로 이동한다.
- 플레이어는 전투마다 한 번, 손패 1장을 다른 패로 교체할 수 있다.
- 카드 교체 기회는 사용 후 해당 전투가 끝날 때까지 다시 생기지 않으며, 다음 전투 시작 시 초기화된다.
- 드로우 더미가 부족하면 버림 더미를 섞어 새 드로우 더미로 만든다.
- 드로우 더미만으로 손패 3장을 채울 수 없다면, 남은 드로우 더미를 먼저 뽑고 버림 더미를 섞어 부족한 수만큼 추가로 뽑는다.

## 턴 흐름

**확정**

1. 턴 시작 효과를 처리한다.
2. 적의 패 2장과 예상 행동을 표시한다.
3. 플레이어가 손패를 3장까지 채운다.
4. 전투당 카드 교체 기회가 남아 있다면 손패 1장을 교체할 수 있다.
5. 플레이어가 패 2장을 제출한다.
6. 양쪽 족보와 상성 효과를 판정한다.
7. 양쪽 패를 비교하고 승자가 패자에게 피해를 적용한다. 무승부라면 피해 없이 넘어간다.
8. 체력과 전투 종료 여부를 판정한다. 예외적으로 양쪽 체력이 동시에 0 이하라면 게임 오버로 처리한다.
9. 제출한 패 2장과 제출하지 않은 패 1장을 모두 버림 더미로 이동하고 다음 턴으로 넘어간다.

**미정**

- 여러 적 전투를 첫 번째 플레이어블에 포함할지 여부

## 족보

### 첫 번째 구현 대상

**확정**

- 끗
- 알리
- 독사
- 구삥
- 장삥
- 장사
- 세륙
- 땡
- 광땡

족보 판정기는 족보의 이름, 등급, 구성 패, 관련 태그를 결과로 반환한다. 피해량은 족보 판정기에서 직접 계산하지 않는다.

### 특수 상성

**실험**

- 적의 광땡을 특정 족보로 무효화하는 땡잡이형 상성
- 낮은 족보가 특정 높은 족보를 잡는 암행어사형 상성
- 상성은 일반적인 족보 서열과 별도의 규칙 데이터로 관리한다.

### 확장 족보

**보류**

- 고도리
- 월견주와 화견주
- 청단, 홍단, 초단을 변형한 2장 족보
- 게임 고유 족보

## 피해와 생존

### 피해 공식

**실험**

첫 구현에서는 다음 후보를 같은 입력으로 비교할 수 있게 만든다.

1. `끗 기반`: 두 월 합의 일의 자리와 족보 보너스
2. `월 합 기반`: 두 월의 합과 족보 보너스
3. `테이블 기반`: 족보별 고정 피해와 카드 보정값

피해 계산 전략은 교체 가능해야 하며, 비교 결과가 기록되기 전에는 기본 공식을 확정하지 않는다. 상세 결정 절차는 `docs/decisions/0001-damage-formula.md`를 따른다.

### 체력과 돈

**확정**

첫 번째 플레이어블에서는 체력과 돈을 분리한다. 돈을 체력으로 사용하는 규칙은 전투와 경제가 각각 검증된 뒤 별도 실험으로 다룬다.

### 전(錢)과 판돈 통합안

**실험**

첫 번째 플레이어블 이후에는 체력과 화폐를 `전(錢)` 하나로 통합하는 방식을 검토한다.

- 플레이어와 적의 생존 수치를 전으로 표시한다.
- 공격에 성공하면 산출된 피해만큼 상대의 전을 가져온다.
- 상대가 가진 전을 넘는 피해는 적용하지 않아 오버킬로 추가 전을 얻을 수 없다.
- 상점과 이벤트를 포함한 거래에서도 플레이어의 전을 지불한다.
- 전을 소비하면 생존력도 함께 줄어드는 위험과 보상의 선택을 만든다.

이 통합안을 사용할 경우의 피해 후보는 다음과 같다.

```text
산출 피해 = 기본 판돈 + 족보 추가 피해 + 캐릭터 능력 보정 + 유물 효과 보정
실제 이전량 = min(산출 피해, 패자의 현재 전)
```

기본 판돈 `5전`은 예시값이며 확정 수치가 아니다. 이 공식은 현재 비교 중인 피해 공식 세 후보를 대체할 수 있는 추가 실험안으로 다룬다.

## 적

**확정**

- 적은 기본적으로 자신의 패 2장과 예상 행동을 공개한다.
- 적의 패 역시 플레이어와 동일한 족보 판정기를 사용한다.
- 일반 적은 화투 열끗에 등장하는 동식물을 변형한다.
- 강한 적과 보스는 인간형 실루엣을 사용할 수 있다.
- 첫 보스의 콘셉트는 12월 비광이다.

**보류**

- 적이 패 한 장을 가리는 기믹
- 다수 적 동시 전투
- 11월과 12월 관련 장기 서사

## 전투 보상과 강화

### 카드 보상

**확정**

- 전투 승리 후 세 장의 후보 중 한 장을 선택할 수 있다.
- 보상은 건너뛸 수 있다.

**미정**

- 보상 건너뛰기에 추가 보상을 줄지
- 후보 생성 시 월, 태그, 희귀도를 어떤 확률로 사용할지

### 강화

**확정**

첫 번째 플레이어블에는 카드의 수치 보정값을 올리는 단순 강화 한 종류만 구현한다.

**보류**

- 광 속성 부여
- 띠 부착
- 월 변경
- 몬스터를 강화 재료로 사용
- 몬스터 포획과 판매

### 카드와 덱의 특수효과

**미정**

족보는 기본적으로 추가 피해를 제공하고, 성장 요소가 특정 족보에 새로운 능력을 더할 수 있다. 다만 효과를 어느 단위에 부여할지는 아직 결정하지 않는다.

- 카드별 효과: 개별 카드를 뽑고 선택하는 의미가 커지지만 카드마다 별도 효과 설계가 필요하다.
- 덱별 효과: 덱의 정체성을 단순하게 보여줄 수 있지만 개별 카드의 차별성이 약해질 수 있다.
- 유물 또는 카드 활성화 단계로 족보 효과를 확장하는 방식도 후보로 둔다.

효과 단위가 결정되기 전에는 범용 카드 효과 시스템이나 덱 효과 시스템을 구현하지 않는다.

## 런 구성

**확정**

첫 번째 플레이어블은 분기 맵 없이 아래 순서를 사용한다.

1. 일반 전투
2. 일반 전투
3. 일반 전투
4. 휴식 또는 카드 강화
5. 12월 비광 보스

### 확장 데모 구성안

**실험**

현재 첫 번째 플레이어블을 완성한 뒤에는 아래처럼 엘리트 전투와 보상을 포함한 스테이지 구성을 검토한다.

1. 귀시장 입장
2. 일반 전투
3. 보상
4. 일반 전투
5. 엘리트 전투
6. 보상
7. 스테이지 보스

이 구성안의 엘리트가 광 중간 보스인지, 스테이지 보스가 12월 비광인지 여부는 미정이다. 따라서 현재 확정된 `일반 전투 3회 → 휴식 또는 카드 강화 → 12월 비광 보스` 구성을 아직 대체하지 않는다.

**보류**

- 분기형 노드 맵
- 상점
- 중간보스
- 유물
- 이벤트 방
