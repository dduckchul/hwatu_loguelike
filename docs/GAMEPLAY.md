# 게임플레이 명세

## 문서 상태

- 이 문서는 구현이 따라야 하는 게임 규칙의 단일 기준이다.
- 각 항목은 `확정`, `실험`, `미정`, `보류` 중 하나의 상태를 가진다.
- 상태가 `실험` 또는 `미정`인 규칙은 비교 가능한 형태로 구현할 수 있지만 기본 규칙으로 확정하지 않는다.

## 게임 핵심

**확정**

플레이어는 화투패로 덱을 구성하고, 매 턴 손패 3장 중 2장을 내어 섯다 족보와 적의 공개 패를 활용해 싸우는 싱글 플레이 로그라이트 덱빌딩 게임이다.

핵심 선택은 다음 세 가지다.

1. 현재 손패에서 어떤 두 장을 낼 것인가.
2. 적의 공개 패와 족보를 이길 조합을 만들지, 상성으로 받아칠 것인가.
3. 전투 보상으로 덱을 두껍게 만들어 새 족보를 열지, 보상을 건너뛰어 덱의 일관성을 유지할 것인가.

## 첫 번째 플레이어블 범위

**확정**

- 플레이어 캐릭터 1종
- 1~10월 패가 한 장씩 들어간 10장 시작 덱
- 한 번에 3장 드로우
- 손패에서 2장 제출
- 적이 이번 턴에 제출할 패 2장 공개. 공개 패 자체를 예상 행동으로 사용
- 양쪽 패를 비교한 뒤 승자가 패자에게 피해 적용
- 일반 적 3종과 12월 비광 보스 1종
- 전투 후 카드 3장 중 1장 선택 또는 보상 건너뛰기
- 같은 월 카드를 덱에 추가해 땡을 만들 수 있음
- 상점에서 카드 강화와 카드 영구 제거
- `일반 전투 3회 → 상점 → 보스`의 짧은 런
- 승리, 패배, 재시작

## 카드와 덱

### 카드 정체성

**확정**

각 카드는 최소한 다음 정보를 가진다.

- 고유 ID
- 월 숫자
- 피, 광, 띠, 열끗 중 하나의 카드 타입
- 화면에 표시할 카드 이미지

같은 월의 서로 다른 패는 고유 ID와 카드 이미지로 구분한다. 현재 규칙 데이터에는 범용 태그 목록을 두지 않는다.

### 시작 덱

**확정**

- 1월부터 10월까지 각 한 장, 총 10장이다.
- 시작 덱에는 같은 월이 없으므로 땡이 나오지 않는다.
- 같은 월 패를 보상으로 추가하는 순간부터 땡 계열 빌드가 열린다.

### 드로우와 순환

**확정**

- 턴 시작 시 손패가 3장이 되도록 뽑는다.
- 플레이어는 2장을 제출한다.
- 제출하고 남은 패는 버린 카드로 이동한다.
- 플레이어는 전투마다 한 번, 손패 1장을 다른 패로 교체할 수 있다.
- 카드 교체 기회는 사용 후 해당 전투가 끝날 때까지 다시 생기지 않으며, 다음 전투 시작 시 초기화된다.
- 드로우 더미가 부족하면 버림 더미를 섞어 새 드로우 더미로 만든다.
- 드로우 더미만으로 손패 3장을 채울 수 없다면, 남은 드로우 더미를 먼저 뽑고 버림 더미를 섞어 부족한 수만큼 추가로 뽑는다.

## 턴 흐름

**확정**

1. 턴 시작 효과를 처리한다.
2. 각 적이 이번 턴에 제출할 패 2장을 공개한다. 이 공개 패가 해당 적의 예상 행동이다.
3. 플레이어가 손패를 3장까지 채운다.
4. 전투당 카드 교체 기회가 남아 있다면 손패 1장을 교체할 수 있다.
5. 플레이어가 패 2장을 제출한다.
6. 양쪽 족보와 상성 효과를 판정한다.
7. 양쪽 패를 비교하고 승자가 패자에게 피해를 적용한다. 무승부라면 피해 없이 넘어간다.
8. 양쪽의 전과 전투 종료 여부를 판정한다. 예외적으로 양쪽 전이 동시에 0 이하라면 게임 오버로 처리한다.
9. 제출한 패 2장과 제출하지 않은 패 1장을 모두 버림 더미로 이동하고 다음 턴으로 넘어간다.

**미정**

- 적이 두 명일 때의 공격 대상 선택과 행동 순서

## 족보

### 첫 번째 구현 대상

**확정**

- 끗
- 알리
- 독사
- 구삥
- 장삥
- 장사
- 세륙
- 땡
- 광땡

족보 판정기는 족보의 이름, 등급, 구성 패, 관련 태그를 결과로 반환한다. 피해량은 족보 판정기에서 직접 계산하지 않는다.

### 특수 상성

**실험**

- 적의 광땡을 특정 족보로 무효화하는 땡잡이형 상성
- 낮은 족보가 특정 높은 족보를 잡는 암행어사형 상성
- 상성은 일반적인 족보 서열과 별도의 규칙 데이터로 관리한다.

### 확장 족보

**보류**

- 고도리
- 월견주와 화견주
- 청단, 홍단, 초단을 변형한 2장 족보
- 게임 고유 족보

## 피해와 전

### 피해 공식

**확정**

승리한 패의 피해는 기본 판돈 `5전`에 족보별 피해를 더해 계산한다.

```text
끗       = 5 + 끗
중간 족보 = 5 + 두 월의 합 + 5
땡       = 5 + 두 월의 합 + 10
광땡     = 5 + 두 월의 합 + 20
```

무승부에는 피해가 없다. 승자가 계산한 피해만큼 패자의 전을 가져가며 실제 이전량은 패자의 현재 전을 넘지 않는다. 상세 결정 기록은 `docs/decisions/0001-damage-formula.md`를 따른다.

### 전(錢)

**확정**

플레이어와 적은 생존 수치와 화폐를 `전(錢)` 하나로 통합해 동일한 규칙으로 사용한다. 코드에서는 이 값을 `Money`로 관리하고 화면과 기획 문서에서는 `전`으로 표시한다.

- 플레이어와 적은 현재 보유한 전을 생존 수치로 사용한다.
- 공격에 성공하면 산출된 피해만큼 상대의 전을 가져온다.
- 상대가 가진 전을 넘는 피해는 적용하지 않아 오버킬로 추가 전을 얻을 수 없다.
- 상점과 이벤트를 포함한 거래에서도 플레이어의 전을 지불한다.
- 전을 소비하면 생존력도 함께 줄어드는 위험과 보상의 선택을 만든다.
- 현재 전이 0이 되면 해당 캐릭터는 패배한다.

실제 전 이전량은 피해 공식과 관계없이 다음 경계를 따른다.

```text
실제 이전량 = min(산출 피해, 패자의 현재 전)
```

현재 샘플 전투는 플레이어 `80전`, 적 `50전`, 기본 판돈 `5전`으로 시작한다.

## 적

**확정**

- 적은 기본적으로 이번 턴에 제출할 패 2장을 공개하며, 공개 패 자체를 예상 행동으로 사용한다.
- 적의 패 역시 플레이어와 동일한 족보 판정기를 사용한다.
- 한 전투에 동시에 등장하는 적은 최대 두 명이다.
- 각 적은 자신의 전, 패턴, 현재 패턴 순서를 독립적으로 가진다.
- 일반 적은 화투 열끗에 등장하는 동식물을 변형한다.
- 강한 적과 보스는 인간형 실루엣을 사용할 수 있다.
- 첫 보스의 콘셉트는 12월 비광이다.

**보류**

- 적이 패 한 장을 가리는 기믹
- 세 명 이상의 적이 동시에 등장하는 전투
- 11월과 12월 관련 장기 서사

## 전투 보상과 상점

### 카드 보상

**확정**

- 전투 승리 후 세 장의 후보 중 한 장을 선택할 수 있다.
- 보상은 건너뛸 수 있다.
- 카드 후보를 선택하면 확인 전까지 선택을 바꿀 수 있으며, 선택한 후보를 다시 누르면 선택이 해제된다.
- 확인하면 선택한 카드 한 장을 `PlayerDeck`에 추가하고, 건너뛰면 덱을 변경하지 않는다.
- 현재 프로토타입은 전체 카드 카탈로그의 `Normal` 카드 중 서로 다른 고유 ID 세 장을 후보로 제시한다.

#### 보상 레벨별 카드 타입 비율

**실험**

보상 레벨이 높아질수록 특수 타입 카드의 등장 확률을 높이는 아래 비율을 초기 플레이테스트 값으로 사용한다. 현재 구현은 보상 레벨 1만 사용한다.

| 보상 레벨 | Normal | Ribbon/Animal | Bright |
|---|---:|---:|---:|
| 1 | 100% | 0% | 0% |
| 2 | 70% | 25% | 5% |
| 3 | 55% | 35% | 10% |

`Ribbon/Animal` 안에서 두 타입을 어떤 비율로 나눌지와 보상 레벨이 상승하는 정확한 조건은 아직 확정하지 않는다.

**미정**

- 보상 건너뛰기에 추가 보상을 줄지
- 후보 생성 시 월을 어떤 확률로 사용할지
- `Ribbon/Animal` 내부 비율과 보상 레벨 상승 조건

### 강화

**확정**

강화는 카드 인스턴스에 레벨이나 변형 상태를 누적하지 않는다. 플레이어 덱에서 선택한 카드를 별도로 작성된 강화 카드 데이터로 교체한다.

- `Normal` 카드만 강화할 수 있다.
- 강화 결과는 `Bright`, `Ribbon`, `Animal` 중 하나다.
- 강화 전후의 월은 반드시 같다.
- 이미 강화됐거나 원래부터 특수 타입인 카드는 다시 강화할 수 없다.
- 교체 후 덱의 카드 수와 카드가 있던 위치는 유지한다.
- 교체된 카드는 강화 카드의 고유 ID, 월, 카드 타입과 이미지를 사용한다.
- 기존 카드의 원본 정보와 강화 이력은 보존하지 않는다.

**미정**

- 일반 카드별로 선택할 수 있는 강화 카드 목록
- 강화 비용과 강화 후보 제시 방식

**보류**

- 몬스터를 강화 재료로 사용
- 몬스터 포획과 판매

### 상점 기능

**확정**

- 상점에서는 카드 강화와 카드 영구 제거만 제공한다.
- 카드 영구 제거는 선택한 카드를 현재 런의 `PlayerDeck`에서 완전히 제거한다.
- 카드 구매, 유물과 그 밖의 서비스는 첫 구현에 포함하지 않는다.

**미정**

- 카드 강화 비용
- 카드 영구 제거 비용
- 카드를 제거할 수 있는 최소 덱 수

### 카드와 덱의 특수효과

**미정**

족보는 기본적으로 추가 피해를 제공하고, 성장 요소가 특정 족보에 새로운 능력을 더할 수 있다. 다만 효과를 어느 단위에 부여할지는 아직 결정하지 않는다.

- 카드별 효과: 개별 카드를 뽑고 선택하는 의미가 커지지만 카드마다 별도 효과 설계가 필요하다.
- 덱별 효과: 덱의 정체성을 단순하게 보여줄 수 있지만 개별 카드의 차별성이 약해질 수 있다.
- 유물 또는 카드 활성화 단계로 족보 효과를 확장하는 방식도 후보로 둔다.

효과 단위가 결정되기 전에는 범용 카드 효과 시스템이나 덱 효과 시스템을 구현하지 않는다.

## 런 구성

**확정**

첫 번째 플레이어블은 분기 맵 없이 아래 순서를 사용한다.

1. 일반 전투
2. 일반 전투
3. 일반 전투
4. 상점에서 카드 강화 또는 영구 제거
5. 12월 비광 보스

### 확장 데모 구성안

**실험**

현재 첫 번째 플레이어블을 완성한 뒤에는 아래처럼 엘리트 전투와 보상을 포함한 스테이지 구성을 검토한다.

1. 귀시장 입장
2. 일반 전투
3. 보상
4. 일반 전투
5. 엘리트 전투
6. 보상
7. 스테이지 보스

이 구성안의 엘리트가 광 중간 보스인지, 스테이지 보스가 12월 비광인지 여부는 미정이다. 따라서 현재 확정된 `일반 전투 3회 → 상점 → 12월 비광 보스` 구성을 아직 대체하지 않는다.

**보류**

- 분기형 노드 맵
- 중간보스
- 유물
- 이벤트 방
