# 0001. 기본 피해 공식 선택

- 상태: 실험 예정
- 결정 대상: 첫 번째 플레이어블의 기본 피해 공식

## 배경

현재 기획에는 두 월의 합을 기본 피해로 사용한다는 설명과, 합의 일의 자리인 끗을 피해로 사용하는 예시가 함께 있다. 광땡 예시에는 월의 합과 추가 피해를 모두 더하는 방식도 등장한다. 이 상태에서 하나를 임의로 구현하면 카드 월별 가치와 족보 가치가 의도하지 않게 고정된다.

## 비교할 후보

### A. 끗 기반

```text
기본 피해 = (월 A + 월 B) % 10
최종 피해 = 기본 피해 + 족보 보너스 + 카드 보정
```

장점:

- 섯다의 끗 개념이 직접 드러난다.
- 숫자가 높다고 항상 강하지 않아 조합 선택이 생긴다.

위험:

- 망통이 0 피해가 될 수 있다.
- 족보가 없는 손의 피해 편차가 작고 전투가 길어질 수 있다.

### B. 월 합 기반

```text
기본 피해 = 월 A + 월 B
최종 피해 = 기본 피해 + 족보 보너스 + 카드 보정
```

장점:

- 피해량을 직관적으로 이해하기 쉽다.
- 카드 강화와 체력 밸런스를 잡기 쉽다.

위험:

- 높은 월 카드가 구조적으로 강하다.
- 끗과 섯다 족보보다 단순 합을 고르는 것이 유리할 수 있다.

### C. 테이블 기반

```text
기본 피해 = 족보별 피해 테이블
최종 피해 = 기본 피해 + 카드 보정
```

장점:

- 모든 족보의 전투 가치를 독립적으로 조정할 수 있다.
- 낮은 월로 구성된 유명 족보도 강하게 만들 수 있다.

위험:

- 규칙을 외워야 하며 직관성이 낮다.
- 테이블 밸런스 작업량이 크다.

### D. 판돈 기반 전 이전

```text
산출 피해 = 기본 판돈 + 족보 보너스 + 캐릭터 능력 보정 + 유물 효과 보정
실제 이전량 = min(산출 피해, 패자의 현재 전)
```

장점:

- 체력, 공격 피해, 화폐가 전이라는 하나의 주제로 연결된다.
- 상점과 이벤트에서 전을 소비하는 행위가 생존 위험과 직접 연결된다.

위험:

- 전투와 경제를 동시에 조정해야 하므로 첫 프로토타입의 검증 범위가 커진다.
- 우세한 쪽이 전을 계속 가져가면 전투의 역전 가능성이 빠르게 사라질 수 있다.
- 캐릭터와 유물이 없는 초기 구현에서는 공식의 일부 항이 작동하지 않는다.

기본 판돈 `5전`은 예시값이며, 이 후보를 채택하더라도 플레이테스트로 별도 결정한다.

## 실험 방법

동일한 시작 덱, 적 패턴, 난수 시드와 플레이 정책으로 네 전략을 각각 실행한다. 판돈 기반 후보는 먼저 전투만 비교하고, 전투와 경제를 각각 검증한 뒤 거래까지 포함해 다시 평가한다.

기록할 값:

- 평균 및 중앙 전투 턴 수
- 턴당 평균 피해
- 손패별 최선과 차선 선택의 피해 차이
- 월별 선택 빈도
- 족보별 선택 빈도
- 0 피해 또는 과도한 피해 발생률
- 적 의도에 대한 카운터 선택률

자동 시뮬레이션 결과와 최소 5회의 직접 플레이 결과를 함께 본다.

## 결정 기준

- 플레이어가 제출 전 결과를 설명할 수 있다.
- 단순히 높은 월 두 장을 고르는 전략이 지배적이지 않다.
- 일반 전투가 목표 턴 범위 안에 들어온다.
- 땡과 특수 족보가 강하지만 다른 선택을 무의미하게 만들지 않는다.
- 카드 중복과 강화가 의미 있는 성장 선택으로 작동한다.

## 아직 결정하지 않은 사항

- 망통의 최소 피해
- 족보별 정확한 보너스
- 목표 전투 턴 수
- 특수 카운터 성공 시 추가 피해 여부
