# 게임플레이 명세

이 문서는 게임 규칙의 단일 기준이다. `확정`만 기본 규칙으로 구현하며 `실험`, `미정`, `보류`는 임의로 확정하지 않는다. 구현 여부는 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)에서 관리한다.

## 핵심 규칙

**확정**

- 1~10월 `Normal` 카드 한 장씩, 총 10장으로 런을 시작한다.
- 턴마다 손패가 3장이 되도록 뽑고 2장을 제출한다.
- 적은 이번 턴에 제출할 패 2장을 공개한다.
- 양쪽 족보를 비교해 승자가 패자에게 피해를 주고 그만큼 전을 가져간다.
- 전투 후 같은 씬의 귀시장에서 덱을 성장시킨다.

핵심 선택은 제출할 두 장, 적의 공개 패에 대한 대응, 상점에서 전과 덱 일관성 중 무엇을 지킬지다.

## 카드와 덱

### 카드

**확정**

카드는 고유 ID, 1~10월 숫자, 타입, 화면용 이미지를 가진다. 타입은 `Normal(피)`, `Bright(광)`, `Ribbon(띠)`, `Animal(열끗)` 중 하나다. 같은 월의 서로 다른 패는 ID와 이미지로 구분한다.

시작 덱에는 같은 월이 없으므로 땡이 나오지 않는다. 상점에서 같은 월의 카드를 추가하면 땡 계열 조합이 열린다.

### 드로우와 교체

**확정**

- 턴 시작 시 손패를 3장까지 채운다.
- 플레이어는 전투마다 한 번, 선택한 손패 1장을 교체할 수 있다.
- 선택 카드가 0장 또는 2장이거나 이미 교체했다면 교체할 수 없다.
- 드로우 더미가 부족하면 버림 더미를 섞어 부족한 수만큼 계속 뽑는다.
- 턴 종료 시 제출한 두 장과 남은 한 장을 모두 버림 더미로 옮긴다.
- 교체 사용 여부는 다음 전투 시작 시 초기화된다.

## 턴 흐름

**확정**

1. 적이 이번 턴의 패 2장을 공개한다.
2. 플레이어 손패를 3장까지 채운다.
3. 남은 기회가 있으면 카드 1장을 교체한다.
4. 카드 2장을 제출한다.
5. 양쪽 족보를 비교하고 결과 연출을 재생한다.
6. 승자의 피해만큼 패자의 전을 이전한다. 무승부에는 피해가 없다.
7. 패배 또는 전투 승리를 판정한다.
8. 전투가 계속되면 손패를 버리고 적 패턴을 진행한 뒤 다음 턴을 시작한다.

**미정**

- 적이 두 명일 때의 공격 대상 선택과 최종 행동 순서

## 족보

### 기본 족보

**확정**

- 끗
- 알리, 독사, 구삥, 장삥, 장사, 세륙
- 땡
- 광땡

족보 판정은 타입, 순위, 끗, 태그와 구성 카드를 반환하고 피해는 별도 계산한다.

### 타입 조합 태그

**확정**

- 제출한 두 장이 모두 `Ribbon`이면 `쌍띠` 태그를 얻는다.
- 제출한 두 장이 모두 `Animal`이면 `쌍열끗` 태그를 얻는다.
- 타입 조합 태그는 족보 순위와 승패를 바꾸지 않는다.
- 해당 족보로 승리하면 `쌍띠` 또는 `쌍열끗` 태그로 피해가 `5전` 증가한다.
- 띠와 열끗이 섞였거나 같은 타입이 한 장뿐이면 추가 피해가 없다.

### 특수 규칙

**실험**

- 광땡을 특정 족보로 무효화하는 땡잡이형 상성
- 낮은 족보가 특정 높은 족보를 잡는 암행어사형 상성

**보류**

- 고도리, 월견주, 화견주, 단 계열과 게임 고유 족보

## 피해와 전

### 피해 공식

**확정**

```text
기본 판돈 = 현재 전투 회차 × 5
끗       = 기본 판돈 + 끗
중간 족보 = 기본 판돈 + 두 월의 합 + 5
땡       = 기본 판돈 + 두 월의 합 + 10
광땡     = 기본 판돈 + 두 월의 합 + 20
쌍띠/쌍열끗 추가 피해 = 5
실제 이전량 = min(산출 피해, 패자의 현재 전)
```

첫 전투의 판돈은 `5전`이고 전투마다 `5전`씩 증가한다. 상세 근거는 [피해 공식 결정 기록](decisions/0001-damage-formula.md)에 있다.

### 전(錢)

**확정**

- 플레이어와 적은 `Money`를 생존 수치와 거래 화폐로 함께 사용한다.
- 공격 성공 시 실제 피해만큼 패자의 전이 승자에게 이동한다.
- 오버킬로 패자가 가진 전보다 많이 얻을 수 없다.
- 상점 지출은 다음 전투의 생존력도 함께 낮춘다.
- 전이 0이 되면 패배한다.

현재 플레이어 시작값은 `80전`이다. 적 시작 전과 패턴은 적 프리팹 및 `EnemyPatternData`에서 관리한다.

## 적

**확정**

- 적도 플레이어와 같은 족보 판정기를 사용한다.
- 각 적은 시작 전, 순환 패턴과 현재 패턴 인덱스를 독립적으로 가진다.
- 한 전투의 구조상 적 1~2명을 지원한다.
- 일반 적은 화투에 등장하는 동식물을 변형한다.

**보류**

- 패 은폐 기믹
- 세 명 이상의 동시 적
- 광 중간 보스와 12월 비광 보스

## 귀시장

### 카드 구매

**확정**

- 마지막 전투를 제외한 전투 승리 후 귀시장에 카드 후보 3장을 표시한다.
- 현재 후보는 전체 카탈로그의 `Normal` 카드 중 서로 다른 ID 세 장이다.
- 방문 중 구매 가격은 성공한 구매 횟수에 따라 `0전`, `20전`, `40전`이다.
- 후보 클릭 시 공용 확인 없이 즉시 구매한다.
- 전이 부족하면 구매하지 않고 후보를 유지한다.
- 구매한 카드는 새 `CardInstance`로 `PlayerDeck`에 추가하고 해당 슬롯을 매진 처리한다.
- 아무것도 구매하지 않고 다음 전투로 넘어갈 수 있다.

**실험**

보상 레벨 도입 시 카드 타입 비율의 초기 후보는 다음과 같다. 현재 구현은 레벨 1만 사용한다.

| 레벨 | Normal | Ribbon/Animal | Bright |
|---|---:|---:|---:|
| 1 | 100% | 0% | 0% |
| 2 | 70% | 25% | 5% |
| 3 | 55% | 35% | 10% |

레벨 상승 조건과 `Ribbon/Animal` 내부 비율은 **미정**이다.

### 카드 강화

**확정**

- 방문마다 한 번 이용할 수 있다.
- 선택한 `Normal` 카드를 같은 월의 `Ribbon` 또는 `Animal` 카드 데이터로 교체한다.
- 특수 타입 카드는 다시 강화하지 않는다.
- 덱 크기와 카드 위치는 유지하고 이전 정의와 강화 이력은 보존하지 않는다.
- 강화 비용은 `15전`이다.

카드별 후보를 따로 작성하지 않고 현재 카탈로그의 같은 월 `Ribbon`, `Animal` 데이터를 후보로 사용한다.

### 카드 영구 제거

**확정**

- 방문마다 한 번 이용할 수 있다.
- 선택한 카드 한 장을 현재 런의 `PlayerDeck`에서 제거한다.
- 제거 비용은 `20전`이다.
- 카드 선택 후 별도의 `버리기` 버튼을 눌러 제거를 확정한다.
- 같은 방문에서 강화와 제거를 모두 이용할 수 있다.

최소 덱 크기는 **미정**이며 현재 데모 구현에는 하한을 적용하지 않는다.

강화와 제거는 카드 구매와 별도 패널에서 대상을 선택한다. 유물, 아이템과 기타 서비스는 **보류**한다.

## 데모 런

### 제출 목표

**확정**

별도 맵이나 경로 선택 없이 같은 씬에서 선형으로 진행한다.

```text
일반 전투 1 → 귀시장 → 일반 전투 2 → 귀시장 → 일반 전투 3 → 런 완료
```

귀시장에서 넘어갈 때 현재 전과 `PlayerDeck`은 유지하고 `BattleDeck`, 적 상태, 손패와 전투 UI를 다음 전투에 맞게 초기화한다. 마지막 전투 뒤에는 상점을 열지 않는다.

### 백로그

**보류**

- 12월 비광 보스와 광 중간 보스
- 엘리트 전투
- 분기형 맵, 이벤트 방
- 유물과 아이템
- 저장 및 불러오기
- 카드별 또는 덱별 범용 특수효과 시스템
