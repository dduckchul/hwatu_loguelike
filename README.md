# Hwatu LogueLike

화투패로 덱을 구성하고, 손패 3장 중 2장을 내어 섯다 족보와 적의 공개 패를 활용해 싸우는 싱글 플레이 로그라이트 덱빌딩 게임입니다.

## 게임 개요

- **장르:** 섯다 기반 로그라이트 덱빌딩
- **전투:** 매 턴 3장의 손패에서 2장을 선택하고, 공개된 적의 패와 족보를 비교해 승자를 결정합니다.
- **성장:** 전투 후 귀시장에서 새로운 패를 구매하고, 추후 구현할 강화와 영구 제거를 이용해 덱을 성장시킵니다.
- **콘셉트:** 화투에 등장하는 동식물을 일반 적으로, 12월 비광을 첫 보스로 재해석합니다.
- **아트 방향:** 저채도 청회색과 먹 번짐을 사용하는 동양 수묵화풍 배경을 지향합니다.

첫 번째 플레이어블은 `일반 전투 → 귀시장 → 다음 전투`를 세 번 반복한 뒤 12월 비광 보스로 이어지는 짧은 런을 목표로 합니다. 귀시장에서는 패 구매를 제공하고, 카드 강화와 영구 제거는 후속 구현으로 추가합니다.

## 개발 일정

최종 제출일은 **2026년 8월 10일**입니다.

### 현재 구현

- 손패 3장 중 2장을 제출하는 전투
- 적의 공개 패와 족보·피해 판정
- 양쪽 패 비교, 승자 피해, 무승부 처리, 덱 순환
- 전투 승리 후 같은 씬에서 귀시장으로 전환
- 귀시장의 카드 후보 세 장, 순차 가격과 즉시 구매
- 넘어가기 후 전투 덱과 현재 적 초기화
- 전투 화면 Fade-In 완료 후 새 손패 세 장 드로우

### 남은 주요 구현

- `StageEncounterData`와 `EnemyEncounterController`를 이용한 스테이지별 적 프리팹 로딩
- 적 능력치 스케일링과 일반 전투 3회 연결
- 귀시장의 카드 강화와 영구 제거
- 12월 비광 보스와 런 완료 흐름
- 전투 애니메이션과 UI 조작감 보완
- WebGL 빌드와 브라우저 전체 흐름 검증

유물, 아이템, 분기형 맵, 저장 기능과 최종 아트는 현재 제출 범위에 포함하지 않습니다.
