# 프로젝트 개요

## 콘셉트

화투패로 덱을 구성하고 손패 3장 중 2장을 내어, 공개된 적의 패와 섯다 족보를 겨루는 싱글 플레이 로그라이트 덱빌딩 게임이다. 체력과 화폐를 `전(錢)` 하나로 통합하며, 전투 뒤에는 별도 맵 없이 같은 씬의 귀시장에서 덱을 정비한다.

## 세계관

귀신과 귀물이 거래하고 교류하는 도시 `귀시장`의 중심에는 모든 승부가 이루어지는 `투전장`이 있다.

> 여기선 도박에서 승리하는 쪽이 형님이다.

비광이 다른 광들의 힘을 빼앗아 귀시장으로 도망친 뒤 투전장은 시장 전체를 집어삼킨 거대한 도박장이 되었다. 주인공 비형은 조정의 명을 받아 비광을 체포하기 위해 투전장으로 향한다.

이 서사는 장기 방향이며, 현재 제출 범위는 일반 적 세 번과 귀시장 성장 흐름에 집중한다. 12월 비광 보스와 광 중간 보스는 미구현 백로그다.

## 프로젝트 범위

- Unity `6000.3.21f1`, 2D/URP, WebGL
- 같은 씬에서 전투와 귀시장을 교대로 진행
- 일반 전투 세 번을 완료하면 `To Be Continued..`를 표시하고 타이틀로 복귀
- 런 동안 플레이어의 전과 `PlayerDeck` 유지
- 전투마다 `BattleDeck`과 적 런타임 상태 재생성
- 유물, 아이템, 분기형 맵, 저장 기능 제외

게임 규칙은 [GAMEPLAY.md](GAMEPLAY.md), 실제 구현 현황과 남은 작업은 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)를 단일 기준으로 사용한다.
